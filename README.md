# Визуализатор графа зависимостей

## 1. Общее описание

Консольный инструмент для анализа зависимостей Python-пакетов. Данные
берутся из репозитория PyPI (JSON API) без pip и сторонних библиотек.
Сейчас реализованы этапы 1 и 2: приём и проверка параметров, получение
прямых зависимостей пакета.

## 2. Параметры и функции

- `--package` — имя анализируемого пакета (обязательный).
- `--repo` — URL репозитория или путь к файлу тестового репозитория
  (обязательный). Для PyPI: `https://pypi.org/pypi`.
- `--repo-mode` — режим: `online` (по умолчанию) или `test`.
- `--output` — имя файла с графом, расширение `.svg`
  (по умолчанию `graph.svg`).
- `--depth` — максимальная глубина анализа, целое число >= 0
  (по умолчанию 3).
- `--filter` — подстрока: пакеты с ней в имени пропускаются.

Как работает получение зависимостей: программа запрашивает
`<repo>/<package>/json`, читает поле `requires_dist` и выводит имена
прямых зависимостей. Необязательные зависимости (`extra`) пропускаются.
Версии пакетов не учитываются, берётся последняя версия.

При ошибке программа печатает «Ошибка: ...» и завершается с кодом 1.

## 3. Запуск и тесты

    ./run.sh --package requests --repo https://pypi.org/pypi
    python3 -m unittest discover -s tests -t .

## 4. Примеры

    ./run.sh --package requests --repo https://pypi.org/pypi
    ./run.sh --package flask --repo https://pypi.org/pypi
