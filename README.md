# Визуализатор графа зависимостей

## 1. Общее описание

Консольный инструмент для анализа зависимостей Python-пакетов. Данные
берутся из репозитория PyPI (JSON API) без pip и сторонних библиотек.
Реализованы этапы 1–3: параметры командной строки, получение прямых
зависимостей, построение графа с учётом транзитивности (DFS с
рекурсией), глубины, фильтра и циклов.

## 2. Параметры и функции

- `--package` — имя анализируемого пакета (обязательный).
- `--repo` — URL репозитория или путь к файлу тестового репозитория
  (обязательный). Для PyPI: `https://pypi.org/pypi`.
- `--repo-mode` — режим: `online` (по умолчанию) или `test`.
- `--output` — имя файла с графом, расширение `.svg`
  (по умолчанию `graph.svg`; используется на этапе визуализации).
- `--depth` — максимальная глубина анализа, целое число >= 0
  (по умолчанию 3). Глубина 1 — только прямые зависимости.
- `--filter` — подстрока: пакеты с ней в имени пропускаются
  (анализируемый пакет не исключается).

Как это работает:

- В режиме `online` программа запрашивает `<repo>/<package>/json`,
  читает поле `requires_dist`, пропускает необязательные зависимости
  (`extra`). Условия окружения (версия Python, платформа) не
  проверяются, версии пакетов не учитываются.
- Граф строится обходом в глубину (рекурсивный DFS). Циклические
  зависимости обнаруживаются, обход не зацикливается, циклы
  выводятся после графа.
- В режиме `test` вместо URL указывается файл. Пакеты в нём названы
  заглавными латинскими буквами. Формат строки: `A: B C` (A зависит
  от B и C), `E:` — зависимостей нет, строки с `#` — комментарии.

При ошибке программа печатает «Ошибка: ...» и завершается с кодом 1.

## 3. Запуск и тесты

    ./run.sh --package requests --repo https://pypi.org/pypi
    python3 -m unittest discover -s tests -t .

## 4. Примеры

    ./run.sh --package requests --repo https://pypi.org/pypi --depth 2
    ./run.sh --package A --repo tests/data/simple.txt --repo-mode test
    ./run.sh --package A --repo tests/data/simple.txt --repo-mode test \
        --depth 1
    ./run.sh --package A --repo tests/data/simple.txt --repo-mode test \
        --filter C
    ./run.sh --package A --repo tests/data/cycle.txt --repo-mode test
