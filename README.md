# Визуализатор графа зависимостей

## 1. Общее описание

Консольный инструмент, который строит граф зависимостей Python-пакета
и сохраняет его в виде изображения SVG. Сейчас реализован этап 1:
приём и проверка параметров командной строки.

## 2. Параметры

- `--package` — имя анализируемого пакета (обязательный).
- `--repo` — URL репозитория или путь к файлу тестового репозитория
  (обязательный).
- `--repo-mode` — режим: `online` (по умолчанию) или `test`.
- `--output` — имя файла с графом, расширение `.svg`
  (по умолчанию `graph.svg`).
- `--depth` — максимальная глубина анализа, целое число >= 0
  (по умолчанию 3).
- `--filter` — подстрока: пакеты с ней в имени пропускаются.

При некорректном значении программа печатает «Ошибка: ...»
и завершается с кодом 1.

## 3. Запуск и тесты

    ./run.sh --package requests --repo https://pypi.org/pypi
    python3 -m unittest discover -s tests -t .

## 4. Примеры

    ./run.sh --package requests --repo https://pypi.org/pypi --depth 2
    ./run.sh --package A --repo repo.txt --repo-mode test --filter C
